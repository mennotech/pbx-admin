# Support

PBX Admin is maintained as an open source project on a best-effort basis. There is no guaranteed response time, uptime commitment, or deployment support agreement.

## Where to Ask

- Use the bug report issue form for reproducible defects in this repository.
- Use the feature request issue form for proposed enhancements.
- Check the README, existing issues, and closed issues before opening a new request.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never disclose them publicly.

## Include in a Support Request

- the application version or commit;
- Python, uv, Podman or Docker, and Fly CLI versions as relevant;
- the command you ran and complete sanitized error output;
- expected and actual behavior;
- minimal reproduction steps;
- relevant configuration with all sensitive values replaced.

Do not include tokens, passwords, Cloudflare audience values, private hostnames, user email mappings, production database files, or PBX data.

## Scope

Maintainers may help diagnose application defects and clarify documented setup. General administration of Cloudflare, Fly.io, FreePBX, Zabbix, Podman, Docker, networking, DNS, TLS, or operating systems may be redirected to those projects' support channels.

Operational emergencies and private deployment work are outside the scope of public issue support.
